# 项目简介

## 核心功能
- **前后端代码及SQL文件**：提供完整的代码及数据库结构文件，方便用户快速搭建系统。
- **万字文档**：详细的技术文档，帮助用户理解系统架构和功能细节。
- **参考导入调试视频**：视频教程，指导用户如何导入和调试系统。
- **讲解视频**：对系统功能和使用方法进行详细讲解。
- **开发工具安装包**：提供开发工具的安装包，确保系统正常运行。
- **智能AI + echarts可视化**：利用智能AI技术和echarts可视化，提升用户体验。
- **管理员功能**：
  - 主页查看
  - 用户管理
  - 小说信息管理
  - 小说分类管理
  - 敏感词管理
  - 论坛分类管理
  - 举报记录管理
  - 留言反馈
  - 社区交流
  - 系统管理
  - 个人中心
- **用户功能**：根据个人喜好，推荐小说和阅读内容。

## 适用场景
- 小说阅读网站
- 阅读平台
- 个人阅读空间

## 技术特点
- **架构**：B/S架构，MVC模式，Web框架设计。
- **开发环境**：IDEA、JDK1.8、Mysql、Maven、Navcat。
- **技术栈**：Java、SpringBoot、Vue。
